One sentence explaining the modern internet to a time traveler from 1800,
built for the [make.fun competition](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

> It is one coffeehouse holding every newspaper and letter in the world, where you may ask anything and hear the world answer at once.

`main.py` writes that sentence to `/output/entry.txt` (132 chars, deterministic,
no clock, no randomness, no network). See [DESIGN.md](DESIGN.md) for the lane
choice, the 10-candidate tournament, and the 1800 word audit.
